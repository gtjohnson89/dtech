Priority 1 · Updated Jul 26, 2026

Big-button TV companion

Planning
9Impact8Feasibility8Profit9Fit9Total
Problem
People living with dementia (and exhausted caregivers) cannot operate modern smart TVs. Too many inputs, apps, PVR menus, and fragile remotes. They need power/volume/one favorite channel or one streaming destination with almost zero choices.
Solution
A caregiver-configured TV companion: either (A) software+hub that locks a Fire TV / Android TV into a single destination with a 3-button physical remote enclosure, or (B) a simpler IR-only big-button path for non-streaming homes. Start with software config + 3D-printed remote shell; avoid medical claims.
Built for
Adult children / spouses setting up TV for a person with moderate cognitive decline at home.
George fit
Software configuration UX + optional companion app + 3D-printed remote enclosure. Can assemble kits and sell direct/Amazon/Etsy without inventing new silicon.

Feasibility

8/ 10 overall

Hardware 8 · Software 7 · Regulatory 9

Consumer electronics accessory + software. Avoid medical device framing. IR learning and Fire TV sideloading are the main tech risks.

Market / profit hypothesis

Need signal: high

Willingness to pay: Caregivers already pay $17-$40 for dumb big-button remotes and ~$200 for care systems. A $79-$149 configured kit is plausible.

Prototype BOM under ~$180 if using Fire TV Cube path; productized IR-only kit BOM can land under ~$35 with printed shell. Software differentiation + setup service is the margin story, not commodity remote plastic.

Caregiver web/app configures allowed destinations, volume ceiling, and power behavior. Device agent on Fire TV / Android TV enforces kiosk-like mode. Optional ESP/IR blaster path for dumb TVs.

Stack: TypeScript · local device agent · optional React caregiver UI · 3D-printed remote shell CAD

Priority 2 · Updated Jul 26, 2026

Auto-answer caregiver call mode

Research
9Impact7Feasibility8Profit9Fit8Total
Problem
The person living with dementia often cannot answer a smartphone call (swipe UI, volume, which app). Family members need a reliable way to open a loud speakerphone path from allowlisted contacts.
Solution
Dedicated Android mode or cheap spare-phone image: auto-answer allowlisted contacts, force speaker, giant hangup affordance, no app clutter. Could ship as setup guide + MDM/kiosk profile, or a dedicated app.
Built for
Long-distance or busy caregivers who need reliable audio check-ins.
George fit
Mostly software / Android profile work. Hardware can be commodity unlocked Android phones.

Feasibility

7/ 10 overall

Hardware 9 · Software 6 · Regulatory 7

Android auto-answer and call screening APIs vary by OEM/version. Accessibility + default-dialer constraints need a spike. Not a medical device if framed as convenience/kiosk.

Market / profit hypothesis

Need signal: high

Willingness to pay: Families pay hundreds for specialized senior phones. A $29-$79 app or $149 configured phone kit could work.

Software margin is excellent if OEM permission hurdles are solved. Hardware-kit margin is thinner but easier to explain.
