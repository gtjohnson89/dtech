Assembly steps

  1. Flash ESP32 with TV Companion base firmware (bench cable).
  2. Seat mic board on header; verify I2S orientation mark facing out.
  3. Wire IR LED to GPIO 4 via 100Ω; heat-shrink tip.
  4. Fit enclosure; leave mute button travel clear.
  5. Pair against living-room box; run channel ± and mute smoke test.

Test protocol

  1. Install with family present; time the setup (target ≤ 20 min).
  2. Three days of independent channel / volume use; helper on-call only.
  3. Night session: confirm volume ceiling and wake-word behavior.
  4. Log every helper call and every failure mode.

Caregiver observations
